# VeriMedia AI 
### Real vs. AI-Generated Image & Video Detection System

##  About the Project
VeriMedia AI is a media verification project designed to analyse images and videos and identify forensic indicators that may suggest whether the media is authentic, AI-generated, or manipulated.

The project focuses on explainable analysis rather than relying only on a black-box prediction.

##  Problem Statement
With the rapid growth of Artificial Intelligence, AI-generated images and videos are becoming increasingly realistic. It is difficult to distinguish genuine media from artificially generated or manipulated content.

VeriMedia AI aims to make media analysis more understandable through digital forensic techniques.

##  Key Features
- Image and video analysis
- EXIF and metadata inspection
- Error Level Analysis (ELA)
- Fast Fourier Transform (FFT) analysis
- Noise and texture analysis
- Video frame consistency analysis
- Explainable analysis results

##  Technologies Used
- Python

- OpenCV
- NumPy

- Pillow
- HTML
- CSS
- JavaScript

##  How It Works
1. Upload an image or video.
2. The system performs relevant forensic analysis.
3. Different analysis results are combined.
4. The application presents an assessment with explanations.
